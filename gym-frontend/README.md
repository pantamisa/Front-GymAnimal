# GymManagement — Frontend

Proyecto final para la asignatura Programación Web - ITM 2026.

## Tecnologías utilizadas
- **React** (Vite)
- **Axios** (Peticiones HTTP)
- **React Router DOM** (Navegación)
- **Bootstrap 5** (Diseño y Estilos)

## Requisitos previos
- Node.js instalado
- El **Backend** del proyecto debe estar corriendo en `https://localhost:7123/api`

## Instalación y ejecución

1. Entrar a la carpeta del frontend:
   ```bash
   cd gym-frontend
   ```

2. Instalar las dependencias:
   ```bash
   npm install
   ```

3. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```

4. Abrir en el navegador: `http://localhost:5173`

## Funcionalidades
- **Gestión de Miembros**: Listado, registro y eliminación.
- **Gestión de Entrenadores**: Listado y registro.
- **Gestión de Clases**: Listado, registro y cambio de estado.
- **Gestión de Membresías**: Asignación de planes a miembros.
